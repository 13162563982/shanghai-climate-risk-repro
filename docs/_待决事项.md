**③ 「海岸线好像来自一家英国大学的平台」——找不到对应产品，但把这份层查清了两件更要紧的事**

先说一个技术前提（这次是从代码里查实的，不是推断）：
`climate_functions.py` 的 `compute_east_sea_coast_distance()` 里，**岸线 = 行政边界线 ∩ DEM 海面掩膜**：
`shoreline = land_gs.iloc[0].boundary.intersection(ocean_union.buffer(tol))`。
也就是说**岸线的几何形状完全来自这份行政边界层**，FABDEM 只负责判定「边界线的哪一段算海」。
所以它没法用别的东西替代，也不是 FABDEM（Bristol）提供的——这一条已经排除。

**查了一圈英国平台，没有一个能对上：**

**对你这个结果的实质影响（重要）：**

- 岸线取的是 `dissolve()` 后的**市域外形**，区县改名/合并不改变外形 → **海岸线长度对这个年代差是稳健的**，不需要重跑。
