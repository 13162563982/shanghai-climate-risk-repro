## 6. 与方案原文的偏离（共 3 处，均为实测驱动，需作者知悉）

1. **`bootstrap.py` 用 `ctypes.CDLL` 全路径预加载，而非方案 §4 WP3.2 写的 `os.add_dll_directory`**。
   依据：原 `run_sensitivity.py` 注释记录了一条实测结论 —— `os.add_dll_directory()` 会让进程进入
   secure DLL-search mode，**反而**使 h5py / rasterio / fiona 无法加载各自子包内的 DLL。
   现做法为**已验证有效**的等价方案。
2. **`tools\audit_manuscript_consistency.py` 的底稿路径改为 `.md` 且缺失即报错**。
   依据：本包底稿是 `.docx`（`paragraph.text` 会吞掉 131 个公式对象），审计器需要纯文本渲染件；
   WP7 产出该 `.md` 后即可直接使用。核心的 `build_table8_row()` 等输出侧逻辑不受影响。
3. **`_sensitivity_results\` 只复制了最新合并件** `sensitivity_all_combined.csv`（56,755 B）。
   依据：方案 §3「明确不复制 … `_sensitivity_results` 历史 csv（只留最新合并件）」。
   WP6 全量重跑会重新生成 `sensitivity_results_<ts>.csv` 系列。

**另有 1 处现场发现（方案未列）**：`env\run.ps1` 用
`param([Parameter(ValueFromRemainingArguments=$true)][string[]]$Rest)` 会**静默吞掉** `--xxx` 形式的
参数（PowerShell 把 `--only` 解析成参数名）。已改用无 `param()` 块 + `$args`，
实测 `--from NOPE` / `--to NOPE` / `--only NOPE` 均正确透传。

### 9.1 现场发现：输出捕获方式会杀死编排器（**重要**）

**实测**：PowerShell 5.1 在收到子进程第一行 stderr 时抛出 `NativeCommandError`，

✅ **唯一安全方式：直接调用，不接管道、不重定向** ——
`& .\env\run.ps1 run_v8.py`（由 `tools\_stderr_probe.py` 的 A/B/C/D 四组对照实测确认）。

## 12. 潮损 −13% 复核（作者指示 #2）— ✅ 完成，结论：**几何伪影，非真实风险变化**

工具：`tools\_verify_surge_offset.py`　报告：`docs\_潮损偏移复核报告.md`（只读，不改任何产物）

### 12.1 因果链（源码定位）

```
ADMIN_BOUNDARY_SHP → dissolve(16 区) = 陆地多边形        climate_functions.py:460-464
  → 岸线 = 陆地边界 ∩ DEM 海洋掩膜                      climate_functions.py:474-490
  → building_coast_distance_m.npy                      climate_functions.py:492-498
  → 淹没深度 = min(TWL−elev, TWL−crest)·exp(−3·cdist/reach)   climate_functions.py:357-362
  → 潮损 EAL
```

边界层只通过**两个**入口影响潮损：① 岸线（→ 岸距场）② 建筑→区县归属。
**本次偏移几乎全部来自 ①。**

### 12.2 决定性证据：官方层导出的岸线只有真实岸线的 28%

| 项 | 旧乡镇层 | 官方 GS(2024)0650 | 变化 |
|---|---:|---:|---:|
| 并集面积 | 7,845.271 km² | 7,205.071 km² | −8.16% |
| Jaccard | — | 87.35% | — |
| **导出岸线长度** | **347.9 km** | **96.2 km** | **−72.3%** |
| 岸距 均值 / 中位 | 18.60 / 18.98 km | 25.50 / 25.73 km | **+6,902 / +2,520 m** |
| 岸距场相关系数 | — | 0.5040 | — |
| 建筑「离岸更远」占比 | — | 364,110（62.2%） | — |
| `coastal_fringe` 分区建筑数 | 190,782 | **96,996** | −49.1% |

**机理**：官方层是**概化**产品（16 区多边形顶点合计 780；dissolve 后并集边界仅 198 顶点）。
把它的边界与 DEM 海洋掩膜求交时，大部分边是**横穿陆地的弦**、根本不落在海上，
于是只剩 96.2 km 的"岸线"。真实岸线长度损失 **72%**。

**后果**：岸距被系统性抬高，而深度按 `exp(−3·cdist/reach)`（reach = TWL/1e-4 ≈ 30 km）衰减 →
`(事件×建筑)` 对中非零深度占比由 **0.237% 降至 0.111%（−53%）** → 城市潮损 EAL **−13.67%**。
