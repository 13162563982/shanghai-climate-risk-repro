1. **并行序** —— 若 `ProcessPool` 导致结果顺序漂移，两次 C01 的 `haz_TC_*.hdf5` 会不同。
   处置：WP4 跑完后，**立刻把 `haz_TC_hist.hdf5`、`haz_TC_synth.hdf5` 的 SHA256 存档**；WP5 跑完再取一次。
   - 若两次 SHA 相同 → C01 完全可复现，A1/A2 的差异可 100% 归因于边界层 ✔
   - 若不同 → **不要继续对比**，先把 **同一个** C01/C02 产物同时供 WP4 与 WP5 使用（见下"共用策略"），并在报告中明确标注"hazard 目录不可逐位复现，故采用共享目录法隔离边界效应"。
2. **Knutson 缩放因子的在线/离线双路径** —— L138-147：
   ```python
   try:
       sc_df = tc_clim_change.get_knutson_scaling_factor(variable="intensity", percentile="50", basin="WP", baseline=(1985, 2005), yearly_steps=1)
   ```
